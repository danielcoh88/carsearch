# מנהל רכישת רכב

אפליקציית React לניהול רכבים בתהליך רכישה.

## התקנה והפעלה

```bash
npm install
npm run dev
```

פתח בדפדפן: http://localhost:5173

## פיצ'רים

- **הוספת רכב** — הדבק קישור מיד2 ושלוף פרטים אוטומטית, או הכנס ידנית
- **ניהול סטטוס** — עקוב אחרי תהליך הרכישה (מעוניין → יצרתי קשר → נסיעת מבחן → משא ומתן → נרכש)
- **הערות** — הוסף הערות עם חותמת זמן לכל רכב
- **שדות מותאמים** — הגדר שדות משלך (טקסט, מספר, דירוג, כן/לא, תאריך)
- **השוואה** — השווה 2-3 רכבים זה לצד זה עם הדגשת הערך הטוב ביותר
- **ייצוא/ייבוא** — גיבוי ושחזור נתונים כ-JSON
- **שמירה מקומית** — כל הנתונים נשמרים ב-LocalStorage בדפדפן
